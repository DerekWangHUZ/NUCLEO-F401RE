# FlowingLED 项目物理电路连接记录

适用开发板：NUCLEO-F401RE（STM32F401RE）。

## 1. 八路流水灯

| LED | GPIO | 连接 |
|---|---|---|
| LED1 | PA10 | PA10 → 限流电阻 → LED → GND |
| LED2 | PB3 | PB3 → 限流电阻 → LED → GND |
| LED3 | PB5 | PB5 → 限流电阻 → LED → GND |
| LED4 | PB4 | PB4 → 限流电阻 → LED → GND |
| LED5 | PB10 | PB10 → 限流电阻 → LED → GND |
| LED6 | PA8 | PA8 → 限流电阻 → LED → GND |
| LED7 | PA9 | PA9 → 限流电阻 → LED → GND |
| LED8 | PC7 | PC7 → 限流电阻 → LED → GND |

所有 LED GPIO 均为推挽输出、无上下拉。程序输出 SET 点亮、RESET 熄灭。每个外接 LED 应串联独立限流电阻，项目未指定阻值；外接电路与 NUCLEO 板必须共地。

## 2. 方向按键

PC13 / DIR_BTN → 按键 → GND。PC13 配置为 GPIO 输入并启用内部上拉：未按下读 1，按下接地读 0。程序检测有效按下后切换流水灯方向。

## 3. 电位器

- 滑动端（中间端）→ PA0 / ADC1_IN0
- 一侧固定端 → 3.3 V
- 另一侧固定端 → GND

PA0 配置为 ADC1 通道 0，ADC 值用于调节约 50–500 ms 的流水灯延时。两固定端接 3.3 V 和 GND 是常规接法，源码未直接说明。不要向 PA0 输入 5 V。

## 4. 板载绿色 LED LD2

板载 LED LD2 连接到 PA5，配置为推挽输出。LD2 不在 8 路流水灯数组中，不参与当前流水显示，无需外接。

## 5. 串口和调试接口

- USART2_TX：PA2
- USART2_RX：PA3
- SWDIO / TMS：PA13
- SWCLK / TCK：PA14

PA2、PA3 为 USART2 复用功能；PA13、PA14 为 SWD 接口，通常由板载 ST-LINK 连接。
